способ первый, простой.
просто запустить программу DefDmgFED V9.0.1.exe (кликнув мышкой), в этом случае воздействие берется из файла wzdi.wzd (этот файл должен быть), а результат запишется в файл ttesgtf.dat (файл создастся сам и будет перезаписываться при каждом запуске программы).

Второй способ, через командную строку (КС).
Запускаем командную строку (жмем win+r, откроется окно поиска, там вводим cmd , жмем enter, откроется консоль, она же КС)
в КС переходим в папку с программой (команда cd адрес_папки ) (адрес можно скопировать и вставить щелкнув правой кнопкой мыши)
для запуска пишем "DefDmgFED V9.0.1.exe" (кавычки обязательны, можно просто написать def и нажать tab ) через пробел файл воздействия (.wzd этот файл должен быть) и через пробел файл для результата (.dat файл создастся сам). Жмем enter и программа запускается.
Этот способ хорош тем что можно сделать несколько файлов воздействия и по очереди запускать их, сохраняя результат в разные файлы.

Третий способ через тотал коммандер
Нужно открыть тотал коммандер или что-то вроде того. Затем открыть папку с программой и ввести через пробелы, как в предыдущем случае, имя программы, файл воздействия, файл для результата.
