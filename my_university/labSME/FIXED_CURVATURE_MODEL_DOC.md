## Модель термоциклирования с фиксированной кривизной (5 уравнений)

Цель: при термоциклировании пластина **не должна менять кривизну** (геометрия “прижата/подперта снизу”), но допускается **незначительное общее удлинение** всей структуры “вправо” (растяжение без изгиба).

Ниже — та система, которую мы прямо реализуем в коде для приращений на каждом шаге по температуре.

### Обозначения (в терминах кода)
- Слои: слой 1 (SMA), слой 2 (эластический).
- Волокна: для каждого слоя рассматриваются “внешнее” и “внутреннее” волокна: `out` и `in`.
- Напряжения и приращения:
  - `x1 = dσ1_out`, `x2 = dσ1_in`, `x3 = dσ2_out`, `x4 = dσ2_in` (в коде именно эти переменные решаются на шаге).
  - Далее средние/изгибные компоненты:
    - `dσ1_mean = 0.5*(x1 + x2)`, `ds1 = 0.5*(x1 - x2)`
    - `dσ2_mean = 0.5*(x3 + x4)`, `ds2 = 0.5*(x4 - x3)`
- Деформации приращений:
  - Для волокон слоя 1 используется (механика SMA + фазовый вклад + температурный вклад):
    - `dε1_out = C1_out * x1 + phase_out + thermal1_term`
    - `dε1_in  = C1_in  * x2 + phase_in  + thermal1_term`
  - Для волокон слоя 2 (только механика + температурное расширение):
    - `dε2_out = C2_out * x3 + thermal2_term`
    - `dε2_in  = C2_in  * x4 + thermal2_term`

### Система (ровно 5 уравнений на шаге)

1) **Равновесие по продольной силе** (N=0 в приращениях):
`h1 * dσ1_mean + h2 * dσ2_mean = 0`

2) **Равновесие по моменту**:
момент вычисляется как `dM = dF * part_len` (и используется формула (18) отчёта для `dF`).

3) **Кинематические условия “без смены кривизны”** (3 равенства приращений деформаций):
   - (a) В слое 1 внешнее и внутреннее волокна меняются одинаково:
     `dε1_out = dε1_in`
   - (b) Внутренние волокна двух слоёв совпадают:
     `dε1_in = dε2_in`
   - (c) Внешние волокна двух слоёв совпадают:
     `dε1_out = dε2_out`

Эти три равенства означают, что **все четыре** приращения по крайним волокнам совпадают:
`dε1_out = dε1_in = dε2_in = dε2_out`

То есть изгиб (смена кривизны) запрещён, но общий сдвиг/удлинение допускается.

### Как в коде проверяется выполнение условий
- Для каждого шага термоцикла мы можем логировать величины:
  - `dε1_out - dε1_in`
  - `dε1_in  - dε2_in`
  - `dε1_out - dε2_out`
- Если они превышают допуск, значит нарушена кинематическая система (либо численная ошибка, либо неверно введены фазовые/тепловые вклады).
