# Формулы по этапам и анализ их корректности

Ниже выделены формулы из кода по каждому этапу и краткий анализ их физической и математической корректности в принятых приближениях.

---

## Общие определения (до этапов)

### Коэффициенты податливости (упрочнение после текучести)

```
podat1_unload = (1 / strengthening_coefficient_1) - (1 / unloading_young_module_1)
podat1_load   = (1 / strengthening_coefficient_1) - (1 / loading_young_module_1)
podat2        = (1 / strengthening_coefficient_2) - (1 / young_module_2)
```

**Модель:** при |σ| > σ_y деформация  
ε = σ/E + (σ − σ_y)·H(|σ| − σ_y)·(1/E_pl − 1/E) = σ/E + (σ − σ_y)_+ · podat.

**Вывод:** dε/dσ = 1/E при σ ≤ σ_y и 1/E_pl при σ > σ_y, значит «дополнительная» податливость после текучести равна 1/E_pl − 1/E = podat. **В приближении линейного упрочнения — верно.**

### Функция Хевисайда

- H(x) = 0 при x ≤ 0, H(x) = 1 при x > 0. Используется для переключения упругий/пластический режим. **Корректно.**

---

## Этап 1 — Loading (снятие с барабана, совмещение торцов)

### 1.1 Деформация внешнего слоя 1

```
eps_start = delta / ((arc_length / rad) * (h1 + h2 + rad) - delta)
```

Обозначения: L_o1 = (arc_length/rad)·(h1 + h2 + rad) — длина внешнего волокна слоя 1 на барабане; после совмещения торцов эта длина должна стать L_o1 − δ. Относительное удлинение внешнего слоя 1:

ε_start = (L_o1 − (L_o1 − δ)) / (L_o1 − δ) = δ / (L_o1 − δ).

**Верно** для заданной геометрии и малых деформаций.

### 1.2 Напряжения в слое 1 (одноосная диаграмма с упрочнением)

```
sig1 = 0.5 * ( H(σ_y1/E1 − eps_start)*(eps_start*E1)
             + H(eps_start − σ_y1/E1)*(σ_y1 + (eps_start − σ_y1/E1)*E_pl1) )
s1   = sig1   (то же значение)
```

В коде затем: sig1_out = sig1 + s1, sig1_in = sig1 − s1 ⇒ σ1_out = 2·sig1, σ1_in = 0. То есть по толщине слоя 1 — линейное распределение: внешнее волокно σ = σ_max, внутреннее 0. Тогда среднее σ1 = σ_max/2 и «полуразмах» s1 = σ_max/2, т.е. σ_max = 2·sig1.

Формула по сути задаёт σ_max:

- при ε ≤ σ_y1/E1: σ_max = ε·E1 (упругость);
- при ε > σ_y1/E1: σ_max = σ_y1 + (ε − σ_y1/E1)·E_pl1 (линейное упрочнение).

**В приближении идеальной упруго-пластичности с линейным упрочнением — верно.** Слой 2 при загрузке не нагружен: sig2 = 0, s2 = 0 — консистентно.

### 1.3 Изгибающий момент (слой 1)

```
bending_moment = h1² * (3*sig1 + s1) / 6
```

При линейном распределении напряжения по толщине h1: σ(η) = σ_in + (σ_out − σ_in)·(η/h1), момент на единицу ширины (b=1):

M = ∫₀^h1 σ(η)·η dη = (σ_in/2 + (σ_out−σ_in)/3)·h1² = h1²·(2·σ_out + σ_in)/6.

С σ_out = sig1+s1, σ_in = sig1−s1 ⇒ 2·σ_out + σ_in = 3·sig1 + s1. **Формула верна** при b = 1.

### 1.4 Упругая деформация (меры кривизны)

```
eps_elastic = (eps1_out - eps2_out) / (2 * (1 + eps2_out))
```

Интерпретация: разность деформаций внешних волокон двух слоёв, отнесённая к 2(1+ε₂_out). В линейном приближении малых деформаций (1+ε) ≈ 1 это даёт (ε1_out − ε2_out)/2 — величина, связанная с разностью удлинений и кривизной. **(1+eps2_out)** может быть учётом конечных деформаций (типа логарифмической/Грина). **В малых деформациях — разумная оценка; точный смысл зависит от вывода (уточнить по источнику, как в define.txt).**

## Этап 2 — Unloading (механическое выпрямление)

### 2.1 Равновесие поперечного сечения

```
d_sig2 = -(h1/h2) * d_sig1
```

Из условия нулевой продольной силы: N1 + N2 = 0 ⇒ h1·Δσ̄1 + h2·Δσ̄2 = 0. При средних напряжениях σ̄1 = sig1, σ̄2 = sig2 получаем h1·d_sig1 + h2·d_sig2 = 0 ⇒ **формула верна.**

### 2.2 Система для d_sig1, d_s1 (метод Крамера)

Коэффициенты (с Хевисайда по текучести):

- A = (D1_unload + podat1_unload·H(|σ1_in|−σ_y1)) / (D2 + podat2·H(|σ2_in|−σ_y2))
- k1, k2 — из приращений деформаций и гипотезы плоских сечений;
- q1 = 3·(h1/h2)² + 4·(h1/h2) + A,  q2 = (h1/h2)² − A;
- Det_Glav = k1·q2 − k2·q1;
- Det_sig1 = -(6·(-1)·d_M / h2²)·k2,  Det_s1 = (6·(-1)·d_M / h2²)·k1;
- d_sig1 = Det_sig1 / Det_Glav,  d_s1 = Det_s1 / Det_Glav;
- d_s2 = (A + h1/h2)·d_sig1 − A·d_s1.

Вывод системы: из связи приращений деформаций с приращениями напряжений (упругость + податливость после текучести) и из равенства кривизн слоёв (гипотеза плоских сечений). **В принятой схеме двухслойной балки и линейного упрочнения — согласовано.**

### 2.3 Приращение деформаций (инкрементальная форма)

```
eps1_out += (d_sig1 + d_s1)/E1_unload
            + podat1_unload·(d_sig1 + d_s1)·H(|σ1_out|−σ_y1)·H(|σ1_out|−|σ1_out_old|)
```
(аналогично для eps1_in, eps2_in, eps2_out с своими d_sig±d_s и модулями/податливостями.)

Это инкрементальная запись зависимости ε = σ/E + (σ−σ_y)_+·podat с учётом того, что пластическая добавка появляется только при росте |σ| за σ_y. **Корректно** для линейного упрочнения.

### 2.4 Проверка гипотезы плоских сечений

В коде выводится отношение (eps1_out − eps1_in)/(eps2_in − eps2_out) и сравнивается с h1/h2. Для линейного распределения ε по высоте отношение приращений деформаций должно соответствовать отношению расстояний от нейтральной оси, т.е. **такая проверка уместна.**

## Этап 3 — Heating (нагрев и доля мартенсита)

### 3.1 Кинетика доли мартенсита Fi

```
d_Fi = -d_t/(m_start - m_finish) * H(1−Fi_old) * H(m_start - Fi_old*(m_start−m_finish) - t)
       - d_t/(a_finish - a_start) * H(Fi_old) * H(t + Fi_old*(a_finish−a_start) - a_finish)
```

Интерпретация: при охлаждении (мартенсит) Fi растёт в интервале температур [m_finish, m_start]; при нагреве (аустенит) Fi падает в [a_start, a_finish]. Линейная по температуре кинетика с отсечками Хевисайда. **Упрощённая, но распространённая модель** для доли фазы (подобно линейному правилу Койна).

### 3.2 Эффективный модуль Юнга и КТР слоя 1

```
D1 = (1−Fi)/E_aust + Fi/E_mart  =>  1/D1 = E_eff
alpha1 = alpha_aust·(1−Fi) + alpha_mart·Fi
```

Смешение свойств по доле фазы. **Стандартное приближение** для двухфазного слоя.

### 3.3 Приращения напряжений при нагреве

```
d_sig2 = (h1/(h2*D1)) * ( sig1*d_D1 + d_alpha1*t + alpha1*d_t + (eps0_heat_out + eps0_heat_in)*d_Fi/2 )
d_sig1 = -(1/D1) * ( sig1*d_D1 + d_alpha1*t + alpha1*d_t + (eps0_heat_out + eps0_heat_in)*d_Fi/2 )
d_s1   = (1/D1) * ( (eps0_heat_in - eps0_heat_out)*d_Fi/2 - podat1_load*d_D1 )
```

Вывод: из равновесия h1·d_sig1 + h2·d_sig2 = 0 и из конститутивного закона слоя 1 с термическим и фазовым вкладом: d_ε1 = d_sig1/D1 + sig1·d(1/D1) + alpha1·d_t + eps0·d_Fi. Тогда d_sig1 выражается через правую часть, а d_sig2 — из равновесия. **В рамках такой одномерной модели и линейной кинетики — согласованно.**

### 3.4 Слой 2 (тепловое расширение и текучесть)

```
d_s2 = -d_sig2 - alpha2*d_t / (D2 + podat2*H(|sig2+s2| − σ_y2))
```
и при Hev(|d_sig2+d_s2|)==0:  
`d_s2 = -d_sig2 - alpha2*d_t/D2`.

Учитывается тепловое расширение и разная податливость при упругом/пластическом состоянии. **Приближённо верно**; проверка в modeling.txt сравнивает d_sig2 с выражением через две ветки (внутреннее/внешнее волокно) — возможны расхождения при переходах через текучесть.

### 3.5 Приращение силы (из момента)

```
d_f = -(h1²/(6*part_len)) * ( 3*d_sig1 + d_s1 - 3*h2²*d_sig2/h1² + h2²*d_s2/h1² )
force += d_f
```

Связь: M = F·part_len (консоль), d_M = d_F·part_len. Момент от слоёв (на единицу ширины):  
M = h1²·(3·sig1+s1)/6 + h2²·(3·sig2+s2)/6.  
Тогда d_M = h1²·(3·d_sig1+d_s1)/6 + h2²·(3·d_sig2+d_s2)/6. Знак минус в d_f может соответствовать знаковой конвенции (реакция консоли). **Формула согласована с равновесием момента**, если момент слоя 2 в коде учтён с той же конвенцией (при необходимости уточнить знак по чертежу).

### 3.6 Восстановленная деформация при нагреве

```
eps0_heat_out = rec_ratio * (eps1_out_max - σ_y1/unloading_young_module_1)
eps0_heat_in  = rec_ratio * (eps1_in_max - σ_y1/unloading_young_module_1)
```

Часть накопленной пластической (сверх упругой) деформации возвращается при фазовом переходе. **Эвристика разумная** (rec_ratio — доля восстановления); точные значения обычно подбирают по опыту.

---

## Этап 4 — Cooling (охлаждение)

Используются те же связи, что и при нагреве, но:

- `eps0_cool_out = lam*eps1_out_strain + (sig1+s1)/young_module_TP`
- `eps0_cool_in  = lam*eps1_in_strain + (sig1−s1)/young_module_TP`
- `d_f` вычитается: `force -= d_f`
- В цикле `while t >= t_finish` используется `Fi_old`, но в начале функции **Fi_old не инициализирован** — это ошибка: нужно задать Fi_old = Fi перед циклом.

Формулы для d_sig1, d_sig2, d_s1, d_s2, d_f — те же по структуре, что при нагреве. **В том же приближении — согласованы;** исправление инициализации Fi_old обязательно.

---

## Деформации от напряжений (слой с текучестью)

Используется в heating (при Fi≤0) и в cooling:

```
eps = σ*D + H(σ − σ_y)·(σ − σ_y)·podat
```

То есть ε = σ/E + (σ−σ_y)_+·(1/E_pl−1/E) = σ/E + (σ−σ_y)_+·podat. **Соответствует принятой диаграмме с линейным упрочнением.**

В cooling есть опечатка: для eps2 считаются два раза eps2_in_strain (второй раз для «out»), один из них должен быть eps2_out_strain.

---

## Краткая сводка по корректности

| Этап / формула | Верность в приближении |
|----------------|------------------------|
| Податливость podat = 1/E_pl − 1/E | ✓ Линейное упрочнение |
| eps_start = δ/(L_o1−δ) | ✓ Геометрия снятия с барабана |
| σ_max(ε) упруго + линейное упрочнение | ✓ |
| M = h1²·(3·sig1+s1)/6 | ✓ Момент при линейном σ по h1 |
| eps_elastic | ○ Требует уточнения вывода (см. define.txt) |
| d_sig2 = −(h1/h2)·d_sig1 | ✓ Равновесие N=0 |
| Система Крамера для d_sig1, d_s1 | ✓ Совместность с гипотезой плоских сечений |
| Инкременты деформаций с H(·) | ✓ |
| Кинетика Fi (линейная по T) | ○ Упрощённая модель |
| D1, alpha1 от Fi | ✓ Смешение фаз |
| d_sig1, d_sig2, d_s1 при нагреве | ✓ Согласованы с равновесием и конститутивным законом |
| d_s2 для слоя 2 при нагреве | ○ Возможны нюансы при переделке (см. modeling.txt) |
| d_f от d_M | ✓ При согласованной конвенции знаков |
| eps0_heat, eps0_cool | ○ Эвристики; rec_ratio и lam — подбор |
| cooling: Fi_old | ✗ Не инициализирован |
| cooling: eps2_out_strain | ✗ Дублирование eps2_in_strain |

**Итог:** В принятых приближениях (двухслойная балка, плоские сечения, линейное упрочнение, линейная кинетика фазы) основные формулы **физически и математически согласованы**. Стоит уточнить вывод eps_elastic, конвенцию знака для силы и исправить баги в cooling (Fi_old, eps2_out_strain).
