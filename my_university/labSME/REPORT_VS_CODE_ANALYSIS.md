## 4. Этап нагрева (heating) — основные источники расхождений

### 4.1 Система уравнений в отчёте (15)–(17)

В отчёте явно задано:
- **dε^out_1 = dε^in_1 = dε^in_2 = dε^out_2 = 0** (условие «жёсткой заделки»: полное приращение деформации в каждом волокне равно нулю).

То есть в каждом волокне:
- **dε_mech + dε^ph_h + d(α·T) = 0.**

В коде:
- Для **среднего** по слою 1 условие нулевого полного приращения по сути выполняется (из него выводятся d_sig1, d_sig2).
- Для **слоя 2** используется одна формула для d_s2; при этом в `modeling.txt` постоянно срабатывает проверка «peredelivay, raznitsa» — то есть **условие для обоих волокон слоя 2 (dε^in_2 = 0 и dε^out_2 = 0) не выполняется** при текущем выводе d_s2.

**Рекомендация:** заново вывести приращения напряжений из системы (15)–(17) отчёта (четыре уравнения dε = 0 + равновесие), явно разрешив её относительно dσ1, ds1, dσ2, ds2, и сравнить с текущими формулами в коде. Скорее всего, потребуется переписать выражение для **d_s2** и, при необходимости, способ расчёта d_sig2, чтобы оба волокна слоя 2 удовлетворяли (15).

### 4.2 Начальная деформация для фазового перехода (ε0 и K)

В отчёте (12): **dε^ph_h = K·ε0·dΦ**, где **ε0 – начальная деформация**.

Физически «начальная» здесь — деформация **перед нагревом**, т.е. **после разгрузки**, а не после нагрузки.

В коде сейчас:
```python
eps0_heat_out = rec_ratio * (eps1_out_max - strenght_yield_1 / unloading_young_module_1)
eps0_heat_in  = rec_ratio * (eps1_in_max - strenght_yield_1 / unloading_young_module_1)
```
используются **eps1_out_max, eps1_in_max** из **loading()**, т.е. деформации **после этапа нагрузки**.

**Ошибка:** для термоциклирования корректнее брать деформации **после разгрузки** (конечные eps1_out, eps1_in из `unloading()`), и при необходимости вычитать упругую часть (σ/E), чтобы получить «пластическую» часть, участвующую в возврате.

**Рекомендация:** передавать в `heating()` деформации после разгрузки и считать:
- `eps0_heat_out = rec_ratio * (eps1_out_after_unload - (sig1_out_after_unload)/E1)` (и аналогично для in),
- либо, если модель отчёта предполагает полную деформацию: `eps0_heat_out = rec_ratio * eps1_out_after_unload` и т.д. Выбор уточнить по постановке (что именно считается «ε0» в отчёте).

### 4.3 Знак усилия (формула (18) отчёта)

В отчёте (18):  
**dF = (h1²/(6L)) · (3dσ1 + ds1 − 3·(h2²/h1²)·dσ2 + (h2²/h1²)·ds2)**  
— без минуса.

В коде:
```python
d_f = -(h1 * h1 / (6 * part_len)) * (3 * d_sig1 + d_s1 - 3 * h2**2 * d_sig2 / h1**2 + h2**2 * d_s2 / h1**2)
force += d_f
```
стоит **минус** перед скобкой.

Если в отчёте F — это «усилие, развиваемое свободным концом ленты» (действие ленты на опору), то реакция опоры = −F. Тогда минус в коде может означать, что в переменной `force` хранится реакция. Для сравнения с экспериментом или с графиками отчёта важно явно зафиксировать: по оси ординат откладывается «сила со стороны ленты» или «реакция». Если нужно совпадение с (18) по знаку — убрать минус или выводить `-list_force` на графике.

**Рекомендация:** добавить в коде комментарий о знаковой конвенции и при необходимости ввести множитель (например, `force_sign = +1` по отчёту) для согласования с текстом и опытом.

## 5. Этап охлаждения (cooling)

В коде есть две явные ошибки:

1. **Fi_old не инициализирован** перед циклом `while t >= t_finish`. В цикле используется `Fi = Fi_old + d_Fi`, но `Fi_old` до первого шага нигде не присваивается. Нужно перед циклом задать `Fi_old = Fi` (входной параметр — доля мартенсита в начале охлаждения).

2. **eps2_out_strain** не считается: дважды присваивается `eps2_in_strain`:
   ```python
   eps2_in_strain = (sig2 + s2) * D2 + ...
   eps2_in_strain = (sig2 - s2) * D2 + ...  # должно быть eps2_out_strain
   ```
   Вторую строку нужно заменить на расчёт **eps2_out_strain** по (sig2−s2).

## 6. Краткий список правок в коде

1. **Нагрев:** передавать в `heating()` деформации **после разгрузки** и считать по ним **eps0_heat_out / eps0_heat_in** (и при необходимости вычитать упругую часть σ/E), чтобы ε0 соответствовал «начальной деформации» перед термоциклированием по отчёту.
2. **Нагрев:** пересмотреть систему для d_sig1, d_s1, d_sig2, d_s2, чтобы она строго следовала (15)–(17); в первую очередь переписать **d_s2** так, чтобы не срабатывала проверка «peredelivay» в modeling.txt.
3. **Нагрев:** явно зафиксировать знак усилия (убрать минус в (18) или ввести константу знака и комментарий).
4. **Разгрузка:** при необходимости вернуть `d_M = 1e-9` для согласия с листингом отчёта (влияние на точность и время счёта).
5. **Охлаждение:** инициализировать **Fi_old = Fi** и **D1_old, alpha1_old** по начальному Fi перед циклом; считать **eps2_out_strain** отдельно от eps2_in_strain; в цикле уменьшать температуру (**t -= d_t**), а не увеличивать; возвращать **list_force[-1]**, а не force[-1].

После этих правок имеет смысл заново сравнить графики усилия и доли мартенсита с ожиданиями и с рисунками отчёта (рис. 2).
