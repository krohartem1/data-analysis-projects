# Этап нагрева: неизменная кривизна и действие подставки

## Постановка (по вашему описанию)

- Биметаллическую пластинку **зажимают в тисках** и проводят термоциклирование.
- Под **свободный край** ставят подставку и **замеряют силу**.
- Модель: **кривизна после снятия с барабана и распрямления не меняется** — пластина «хочет» изогнуться при нагреве, но **не может** из‑за подставки.
- Оставляем: **упруго‑пластический подход**, **гипотезу плоских сечений**, **неразрывность деформаций** между слоями.
- Нужно явно учесть: **действие подставки** (реакция = измеряемая сила) и **неизменность кривизны**.

## Условие неизменной кривизны и подставка

- **Кривизна постоянна** ⇒ распределение деформации по толщине не меняется ⇒ приращения деформации во всех волокнах **одинаковы**: dε^out₁ = dε^in₁ = dε^in₂ = dε^out₂ = λ.  
- Заделка в тисках + подставка под свободный конец дают нулевое приращение длины каждого волокна в кинематике модели ⇒ принимаем **λ = 0**, т.е. **(15)** в виде **все четыре dε = 0**.

Тогда:
- в каждом волокне **полное приращение деформации** (механика + фаза + температура) равно нулю;
- равновесие (5) по-прежнему выполняется;
- усиление на подставке считается по **(18)** от приращений напряжений, найденных из (15)+(5)+(9)–(17).

## Вывод системы для dσ₁, ds₁, dσ₂, ds₂

Обозначения:
- σ₁, s₁: среднее и полуразмах в слое 1; σ^out₁ = σ₁+s₁, σ^in₁ = σ₁−s₁.
- σ₂, s₂: в слое 2; σ^in₂ = σ₂+s₂, σ^out₂ = σ₂−s₂ (по конвенции отчёта для слоя 2).
- R_out = K·ε₀_out·dΦ + α₁·dT + (dα₁)·T, R_in = K·ε₀_in·dΦ + α₁·dT + (dα₁)·T.
- Податливости (при необходимости пластичности): C^out₁ = 1/E₁ + podat₁·H(…), C^in₁ = 1/E₁ + podat₁·H(…). В упругом случае C = 1/E₁ = D₁.

**(15)** и **(16)–(17)** дают четыре уравнения (все полные dε = 0):

1. **(A)** (dσ₁+ds₁)·C^out₁ = −R_out  
2. **(B)** (dσ₁−ds₁)·C^in₁  = −R_in  
3. **(C)** (dσ₂+ds₂)/E₂ + α₂·dT = 0 ⇒ dσ₂+ds₂ = −E₂·α₂·dT  
4. **(D)** (dσ₂−ds₂)/E₂ + α₂·dT = 0 ⇒ dσ₂−ds₂ = −E₂·α₂·dT  

Из (C) и (D): **ds₂ = 0**, **dσ₂ = −E₂·α₂·dT**.  
Из **(5)**: **dσ₁ = −(h₂/h₁)·dσ₂ = (h₂/h₁)·E₂·α₂·dT**.

Подставляя это dσ₁ в (A) и (B), получаем два выражения для **ds₁**:
- из (A): ds₁ = −R_out/C^out₁ − dσ₁;
- из (B): ds₁ = dσ₁ + R_in/C^in₁.

В общем случае они совпадают только при определённой связи между R_out, R_in, C^out₁, C^in₁ и dσ₁ (т.е. dT и dΦ). Иначе (15) для обоих волокон слоя 1 и (5)+(C)(D) для слоя 2 **переопределяют** систему.

**Варианты реализации:**

- **Вариант A (текущий код):** формулы, полученные из условия нулевого полного приращения по **среднему** по слою 1 и равновесия; для слоя 2 одна формула для ds₂. Кривизна и оба волокна слоя 2 не гарантированы.
- **Вариант B (рекомендуемый):** «по слою 2 и равновесию» — задаём dσ₂, ds₂ из (C)(D), dσ₁ из (5), затем **ds₁** берём как **полусумму** двух выражений из (A) и (B). Так выполняются (15) для слоя 2 и (5), а для слоя 1 усредняем два волокна — кривизна слоя 1 приближённо сохраняется.
- **Вариант C:** «по слою 1» — из (A)(B) находим dσ₁ и ds₁ (при условии совместности (A)(B)), затем dσ₂ из (5). Тогда (15) для слоя 2 не выполняются оба сразу — допускаем малое изменение кривизны слоя 2.

В коде реализованы **вариант A** (текущий `heating`) и **вариант B** (`heating_constant_curvature`). Константа кривизны и действие подставки учтены через (15) и (18).

## Что подправить в формулах и расчётах

1. **Явно решать систему (15)+(5)** для приращений напряжений (как в варианте B или C), а не выводить только из среднего по слою 1.
2. **Начальная деформация ε₀** в (12): брать деформации **после разгрузки** (уже исправлено в коде).
3. **Знак усилия (18):** в отчёте F — «усилие, развиваемое лентой»; при необходимости выводить на график `-list_force`, если в коде хранится реакция подставки.
4. **Слой 2:** при строгом (15) для обоих волокон получается ds₂ = 0 и dσ₂ = −E₂·α₂·dT; если в коде используется другая формула для ds₂ — заменить на эту в варианте с фиксированной кривизной.
5. **Проверка:** после шага нагрева проверять, что приращения полной деформации по волокнам близки к нулю (и при необходимости выводить в modeling.txt).
